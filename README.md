# Ai_assisted_design
This project used ai to build (almost) the entire site to see what kind of time could be saved on early steps. Implementation was done using outside models online, and the built in VS Code CoPilot.
While the use of ai did help speed the process, or cut out the need for specific knowledge in wed building using html, css, and javascript I dont think the task could be completed without prior knowledge.
There were multiple instances of having to redirect the ai in what libraries it was using for the site, and issues of manually implementing script reference in other documents.
